Versioned docs for the almond website (docusaurus-based)

These are in the Docusaurus 3 format: `versioned_docs/version-X` has all the docs of version `X`,
and `versioned_sidebars/version-X-sidebars.json` its sidebar. They're checked out when building
the website on the CI of [almond-sh/almond](https://github.com/almond-sh/almond), and the docs of
each new release are pushed here from there.
